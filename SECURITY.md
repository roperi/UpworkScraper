# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| `main` | Yes |
| Older revisions | No |

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues, pull requests, or
discussions.

If private vulnerability reporting is enabled for this repository, use the **Report a
vulnerability** option in the repository’s **Security** tab. This creates a private report that
can be reviewed by the maintainers.

Please include:

- a clear description of the vulnerability and its potential impact;
- the affected version, commit, or configuration;
- reproducible steps or a proof of concept, where safe to provide; and
- any suggested mitigation.

Please allow the maintainers reasonable time to investigate and prepare a fix before making the
issue public. Do not include real credentials, session cookies, database files, or other private
user data in a report.

If the private reporting option is unavailable, contact the repository maintainer privately
through the [roperi GitHub profile](https://github.com/roperi) and do not disclose the details
publicly.
